# LAB 12 : Localisation temps réel via GPS et Google Maps

## 📖 Description
Application Android permettant de récupérer la position GPS en temps réel, l'envoyer vers un serveur PHP et l'afficher sur Google Maps.

---

## 🛠️ Technologies utilisées

- Android (Java)
- Google Maps API
- PHP (API REST)
- MySQL
- Volley (requêtes HTTP)

---

## ⚙️ Fonctionnalités

- 📡 Récupération GPS en temps réel
- 📤 Envoi des coordonnées vers serveur PHP
- 🗄️ Stockage dans MySQL
- 🗺️ Affichage des positions sur Google Maps
